# Propuesta: fichas de elemento para agrupar datos en un solo waypoint

Contexto: OSMTracker crea un waypoint por cada botón tocado, por lo que los atributos de un mismo elemento (p. ej. un árbol) quedan en waypoints separados y sin relación. Ver issue#707 del repositorio oficial.

Contenido:
- `01-analisis.md`: análisis del problema.
- `02-propuesta.md`: enfoques, alternativa elegida y flujo de interacción.
- `03-donde-implementar.md`: dónde deberían hacerse los cambios.
- `img/`: diagramas y maqueta del botón compuesto.

Este fork **no implementa** la funcionalidad; solo documenta la propuesta y señala dónde implementarla.
